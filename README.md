# homebrew-reap

[![License](https://img.shields.io/badge/license-MIT-green)](https://github.com/woksin/reap/blob/main/LICENSE)

Homebrew tap for [reap](https://github.com/woksin/reap): find the stale developer junk on your machine and prune only what you can afford to lose.

```bash
brew tap woksin/reap
brew trust woksin/reap   # Homebrew 6 gates third-party taps
brew install reap
```

Or in one step: `brew install woksin/reap/reap`.

`Formula/reap.rb` is written by the release workflow in the [reap](https://github.com/woksin/reap) repository. Do not edit it by hand.

Usage, options and documentation live in the [main repo](https://github.com/woksin/reap).
